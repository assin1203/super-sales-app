## 二、修复的问题

### 2.1 「我的」页顶部被状态栏遮挡（0.1.6）

页面头部原来从屏幕最顶端开始排版，状态栏文字压住头像和昵称。

修复方式：头部内容统一下移一个状态栏高度，渐变背景仍然铺满到状态栏后面，视觉上保持沉浸式，不做成普通标题栏。

### 2.2 首页多余的房间 / 积分礼包模块（0.1.4）

首页不需要展示房间档位卡和「积分礼包」横幅，已整块隐藏（不留空态提示、不留占位）。

### 2.3 装机申请「他人使用」可以随便填号码（0.1.5）

原来选「他人使用」只填手机号就能提交，无法确认号码真实性和归属。

修复后：

- 选「他人使用」才出现验证码输入区，选「自己使用」不受影响；
- 发验证码前必须先通过拼图滑块，防止被刷短信；
- 服务端校验验证码通过后才允许提交，60 秒冷却与倒计时一致；
- 同一号码在本次页面停留内只需验证一次，不会反复弹；
- 号码未注册时自动建号并绑定当前用户为推广人，且**即使随后申请提交失败，也照常提示**「已自动注册并绑定为你的下级」，避免用户误以为没注册成功而重复操作。

### 2.4 只能密码登录（0.1.5）

登录页新增「密码登录 / 验证码登录」切换。验证码登录同样先过滑块再发码；号码未注册时明确提示「未注册，请先注册」，不再笼统报错。

### 2.5 本人手机号显示成星号（0.1.4）

原来所有手机号一律脱敏，本人查看自己的座位、资料、装机申请时也看不到完整号码，无法核对。

修复后：**只有本人号码**在以下三处显示全号，他人号码仍保持脱敏。

- 团队房间中自己的座位；
- 「我的」页手机号；
- 「我的机器 / 装机申请」列表中本人申请单。

### 2.6 收货地址省市区要手打（0.1.3 / 0.1.4）

收货地址表单改为省 / 市 / 区三级联动选择（内置省市区数据，不依赖第三方服务），详细地址仍手填；新增与编辑共用同一套表单。

### 2.7 结束的房间看不到时间（0.1.6）

已结束的房间原来没有时间信息。现在每张已结束房间卡片显示两行：

- 「开始于 …」（房间创建时间）
- 「完成于 …」（归档时间；归档时间缺失时用该房间最后一次分红结算时间兜底）

数据确实缺失时显示「开始时间未记录」「完成时间未记录」，不显示假时间。

## 三、新增功能

### 3.1 团队页 L1 / L2 选项卡带上线昵称（0.1.6）

选项卡标签由纯 `L1` / `L2` 变为 `L1 张三` / `L2 李四`，进页时补拉一次个人资料；未绑定上线或对方没有昵称时自动退回纯 `L1` / `L2`，不会出现「L1 null」。

### 3.2 已结束房间标记「最先拿到贡献值」的人（0.1.6）

已结束房间的座位板上，**最早拿到贡献值**的那位成员头像右上角带皇冠 👑。

判定口径是「该房间最早一条分红记录的得主」，不是贡献值最高的人；未结束的房间不显示皇冠。

### 3.3 收货地址支持编辑（0.1.4）

地址列表可进入编辑，省市区与详细地址都可修改。

## 四、服务端配套变更（必须与本版本一起上线）

| 变更 | 说明 |
| --- | --- |
| `POST /user/login/code` | 验证码登录，复用短信一次性校验 + 双 token 签发 |
| `POST /pos/apply/verify-phone` | 他人使用号码验证；通过后写 10 分钟有效标记，`apply` 时强制消费 |
| 错误码 `41029` | 他人使用手机号未验证 / 验证已过期 |
| `GET /user/me` 新增 `lv1ReferrerNickname`、`lv2ReferrerNickname` | 团队页选项卡昵称来源 |
| 房间 VO 新增 `startedAt`、`endedAt`、`firstContributionUserId` | 房间起止时间与皇冠标记来源 |
| 分红统计合并为一次查询 | 房间列表不再逐房查询分红，接口耗时随房间数线性增长的问题已消除 |

老客户端兼容：`apply` 收到缺省 `useType` 或 `useType=1` 时不校验验证标记，旧包仍可正常提交。

## 六、升级与发布注意

1. **必须先发布服务端**：验证码登录、他人使用验证、房间时间与皇冠字段都依赖新接口，旧服务端会返回 404 或缺少字段。
2. 把安装包上传到下载目录（`/var/www/download/kqw-0.1.6.apk`）。
3. 后台版本记录改为「版本名 `0.1.6` / versionCode `7`」，下载地址指向新包；否则 App 冷启动的更新提示仍指向旧包。
4. App 需要**冷启动**（完全退出后重新打开）才会触发版本检查，仅切后台不触发。

## 七、已知限制

- 支付收银台尚未接入支付 SDK，下单后仅提示「待接入支付」；
- 平台公告后端暂无接口，首页只留占位说明，不展示假数据；
- 短信验证码依赖生产环境短信配置（密钥、签名、模板），未配置时发码会失败；
- 房间时间若服务端两处来源都没有（既无归档时间也无分红记录），界面显示「未记录」，属数据缺失而非显示问题。
