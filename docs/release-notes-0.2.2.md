## 二、相对 0.2.1 的变化

### 2.1 申请列表「立即装机」从弹窗改成独立页面

「我的机器 → 申请中」里，审核通过的申请单点「立即装机」不再弹出对话框，而是进入一个整页：

- 全屏页面，标题「安装 POS 机」，字段自上而下滚动，装机现场填 9 项（机器号、客户姓名、客户手机号、身份证号后 6 位、安装方式、品牌、类型、流量费备注、开机时间、备注、门店补录三项）不再被弹窗高度和键盘挤压；
- 「确认装机」按钮固定在页面底部，键盘弹出时不会被顶出屏幕；
- 提交中不可返回（系统返回手势与 AppBar 返回键都拦下），避免出现「以为没提交、其实后端已装机成功」的重复装机；
- 装机成功后照旧回到申请列表，提示「装机成功，已转入「已安装」列表」并自动刷新。

字段、预填值、校验规则、提交参数与原来的弹窗**完全一致**，只是容器变了。

### 2.2 「我的」页去掉「积分礼包」入口

- 「我的」页功能宫格由 9 个变成 8 个（两行四列），移除「积分礼包」这一格；
- **礼包页本身没有下线**，「积分中心 → 积分礼包」入口仍在，也可以继续直接访问 `/packages`；
- 这样改是因为首页与积分中心都已有礼包入口，个人中心这一格重复且易误触。

### 2.3 推广二维码卡片字号放大

推广中心长按保存的二维码图（屏幕显示与导出的 PNG 同步生效）：

- 推广码字号 `13 → 26`，底部「超级展业 · 邀请注册」文案 `10 → 20`；
- 行间距与文案间距一并放大（`8 → 10`、`2 → 4`），保存出来的图片在微信里放大后仍然清晰可读。

| 功能 | 要点 |
| --- | --- |
| 首页「机器达标监控」 | 一台未达标机器一张卡：序号标题、状态胶囊、剩余天数大号数字（≤3 天转红）、门店名·机号、底部达标规则；剩余天数每次打开/下拉刷新按当前时间重算 |
| 添加机器页「商户名称」 | 选填、留空不提交、不覆盖申请单已有值；首页监控卡的门店名即取自此 |

| 升级提示弹窗 | 有冻结奖励且可用积分够下一档礼包时询问：选升级则自动进房并解冻奖励，选放弃则奖励立即转直接推荐人；30 天到期转推荐人保留为兜底 |
| 推广中心精简 | 统计卡、三级人数分布、下级明细三个模块隐藏（后端接口与数据仍在，开关常量可恢复） |
| 申请 POS 页精简 | 品牌 / 类型 / 所属平台三个下拉不展示、也不请求字典接口 |

## 四、服务端配套（与 0.2.1 相同，须一起上线）

App 依赖后端已包含以下内容，**后端未更新时相关功能整体降级为「不显示 / 不弹」**：

- 机器列表出参新增 `merchantName` / `installedAt` / `dueAt` / `windowDays` / `taskSelfPoints`；
- 新增接口 `GET /pos/newbie/confirmations`、`POST /pos/newbie/confirm`、`GET /team/upgrade-prompt`、`POST /team/upgrade-prompt/choice`；
- 新表 `pos_newbie_confirm`，由发布迁移闸门执行 `db/migrations/20261120_pos_newbie_confirm.sql` 建表；**跳过迁移直接发新镜像，确认接口会 500**。

2.2 本身**没有**新增任何接口或迁移要求。

- 安装包为 release 签名（证书 `CN=KQW, OU=Mobile, O=KQW, L=Beijing, ST=Beijing, C=CN`，SHA-256 `3b5c61b4b58fb7970fa0dd57b59768fb1af3c489fa47eecf7a380d4367495b13`），与 `0.1.9`、`0.1.8` 一致，可直接覆盖升级；
- **后台版本记录要改成 `0.2.2` / versionCode `13`**，下载地址指向 `https://zhy-h5.citykafei.com/download/kqw-0.2.2.apk`；不改的话 App 冷启动的更新提示只会推到旧版本；

## 七、已知限制

- 「立即装机」独立页不显示商户名称输入之外的门店信息补录校验（门店名称 / 所在地区 / 详细地址仍为选填，留空由后端沿用申请单）；
- 「积分礼包」在个人中心已无入口，用户需从积分中心进入，客服话术需同步；
- 已达标但窗口已过的机器不列入首页监控；
- 自装机器没有门店名快照，监控卡显示机型。
