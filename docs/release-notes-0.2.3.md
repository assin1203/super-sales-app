`0.2.3` 是 `0.2.2` 的增量小版本，**没有接口变更、没有数据库变更**，App 侧只做了一件事：关掉两个自动弹窗。安装包使用与历史版本相同的 release keystore 签名，可直接覆盖安装，**不需要卸载**。

## 二、相对 0.2.2 的变化

### 2.1 关闭两个自动弹窗

冷启动与每次回到前台，App 不再自动弹以下两个对话框：

| 弹窗 | 原来的触发条件 | 关闭后的行为 |
| --- | --- | --- |
| 升级提示 | 名下有未结算的装机冻结奖励、可用积分够进下一档礼包、且不是 L2 | 不再询问是否升级，也不再弹「暂不升级」二次确认 |
| 机器达标双方确认 | 有「对方已确认、我还没确认」的未达标机器 | 不再弹多选确认框 |

关闭后不只是不弹框，**连 `/team/upgrade-prompt` 与 `/pos/newbie/confirmations` 两个接口都不再请求**，冷启动和回前台完全静默，不会因为这两个请求拖慢启动。

开关放在 `appRouter` / `ShellLayout` 的 `enableDialogs` 参数上，默认 `false`；弹窗组件、接口封装、后端逻辑全部保留，需要恢复时把默认值改回 `true` 即可。

**业务影响（务必同步给运营与客服）：**

- 冻结奖励不再有「窗口内主动升级 → 解冻给本人」的入口，只能等 **30 天到期兜底自动转给直接推荐人**（无推荐人时兜底给本人）；
- 机器达标不再走「双方确认 + 流水达门槛 → 自动达标发奖」链路，未达标的机器仍需**后台人工审核**处理；
- 两个接口在生产环境不会被调用，后台日志里看不到请求属于正常现象。

## 五、服务端配套

App 依赖的后端能力与 0.2.2 相同，**后端未更新时相关功能整体降级为「不显示」**：

- 机器列表出参包含 `merchantName` / `installedAt` / `dueAt` / `windowDays` / `taskSelfPoints`；
- 双方确认与升级提示四个接口仍在（`GET /pos/newbie/confirmations`、`POST /pos/newbie/confirm`、`GET /team/upgrade-prompt`、`POST /team/upgrade-prompt/choice`），但 0.2.3 的 App 不再调用；
- 新表 `pos_newbie_confirm` 及迁移 `db/migrations/20261120_pos_newbie_confirm.sql` 仍建议随发布闸门执行，后续重新开启确认功能时不必再补建表。

本次后端另有一处随发布上线的修复（App 不依赖，但影响房间分配）：

- `RoomEntryService.enter` 按档位加行锁（`SELECT ... FROM room_package WHERE id = ? FOR UPDATE`）串行化「找房 → 建房 → 占位」，修复多人同时进同一档位房时各自建一个只有自己的房（线上曾把 600 档一次裂成 3 个房）。

`0.2.3` 本身**没有**新增任何接口或数据库变更。

## 七、升级与发布注意

- 安装包为 release 签名，与 `0.1.9`、`0.2.1`、`0.2.2` 一致，可直接覆盖升级；
- **后台版本记录要改成 `0.2.3` / versionCode `14`**，下载地址指向 `https://zhy-h5.citykafei.com/download/kqw-0.2.3.apk`；不改的话 App 冷启动的更新提示只会推到旧版本；
- release 包默认连生产 `https://zhy-api.citykafei.com`，不含内网明文 HTTP 放行，也不要加 `--dart-define` 覆盖后端地址；
- `--debug` 包与 release 包签名不同，手机上一旦装过 debug 包，必须先卸载才能装正式包（卸载会清本地登录态，需重新用手机号验证码登录）。

## 八、已知限制

- 两个自动提醒关闭后，冻结奖励只能等 30 天兜底转推荐人，机器达标只能走后台人工审核；
- 首页「机器达标监控」只取机器列表第一页 20 台，名下超过 20 台时第 21 台起不会出现在监控卡（可在「我的机器」分页查看）；
- 首页监控空态在「全部机器已过期但未达标」时仍显示「机器均已达标」，该文案与实际状态不一定一致；
- 推广中心隐藏统计模块后，`GET /user/invite/records` 仍会随页面打开与下拉刷新请求一次，结果不渲染；
- 已达标但窗口已过的机器不列入首页监控；
- 自装机器没有门店名快照，监控卡显示机型。
